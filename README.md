# Hi there, I'm Aaron Manuel Custodio 👋

### 💻 Software Engineer · 🤖 AI Specialist · 📋 Project Manager · 🎮 Game Developer

I'm a fresh Information Technology graduate from Pamantasan ng Lungsod ng Valenzuela who loves building things, from web systems and mobile games to AI-powered apps. My capstone, **Rumini 2.0**, is an NLP chatbot that speaks English, Tagalog, and Taglish and includes a crisis-safety detection layer. It earned 3rd Place Best Presentation at the CEIT Research Colloquium. I enjoy leading teams as much as writing code, and I'm open to roles in software development, QA, and project management.
